# داونلودنج

تطبيق ويب (PWA) لتحميل الفيديوهات من يوتيوب وتيك توك وانستجرام وفيسبوك وتويتر، كل منصة في قسم لوحدها، وبثلاث جودات (عالية / متوسطة / منخفضة).

## التشغيل على جهازك (للتجربة)

```bash
pip install -r requirements.txt
# لازم ffmpeg يكون منصّب (لدمج الصوت والصورة)
python server.py
```

افتح: http://localhost:8000

## النشر على سيرفر (علشان يشتغل من الموبايل)

أي استضافة بتدعم Docker (Render / Railway / Fly.io / VPS):

```bash
docker build -t downloading .
docker run -p 8000:8000 downloading
```

بعد ما يشتغل على رابط، افتحه من الموبايل واختار **"إضافة إلى الشاشة الرئيسية"** يظهر لك كتطبيق اسمه **داونلودنج** بأيقونة سهم التنزيل.

## حل مشكلة "فشل التحميل لأن جودة الفيديو قديمة"

السبب الغالب إن المكتبة (yt-dlp) قديمة أو الصيغة المطلوبة مش موجودة للفيديو. الحل هنا:

1. **سلسلة بدائل للجودة:** لو الجودة المطلوبة مش متاحة، بيجرب الأقل تلقائيًا لحد ما ينجح بدل ما يفشل.
2. **تحديث تلقائي لـ yt-dlp** عند التشغيل وكل 12 ساعة (المنصات بتغيّر نظامها باستمرار).

## متغيرات اختيارية

- `COOKIES_FILE` : مسار ملف cookies.txt (مفيد لفيديوهات انستجرام/فيسبوك اللي بتطلب تسجيل دخول).
- `PROXY_URL` : بروكسي لو الاستضافة عليها حظر من المنصة.
- `PORT` : رقم المنفذ.

## ملاحظات

- تيك توك: بيحاول ينزّل النسخة بدون علامة مائية، والنتيجة بتعتمد على اللي المنصة بتسمح بيه وقت التحميل.
- انستجرام وفيسبوك: الفيديوهات الخاصة محتاجة cookies.
- حمّل بس المحتوى اللي ليك حق فيه أو المسموح تحميله.
